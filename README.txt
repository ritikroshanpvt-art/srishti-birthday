# Srishti — The 19th Birthday Experience

A three-page Royal Purple + Pink birthday website.

## Files to upload to GitHub Pages
Upload the contents of this folder to the repository root:
- `index.html`
- `memories.html`
- `wish.html`
- `assets/` (contains CSS, JavaScript, photos, and `inaam.mp3`)

Keep the `assets` folder name exactly as it is. GitHub Pages should publish from branch `main`, folder `/(root)`.

## Music
The page attempts to continue music after the first user gesture. Browsers may block autoplay with sound until the visitor taps **Unlock your surprise** or **Play Music**. This is a browser restriction, not a website error.

## Personalization
The birthday wish is a starter message. Replace the text in `wish.html` with the final personal paragraph when ready.
